อัปเดตข้อมูลแดชบอร์ดน้ำท่วม

หน้านี้สำหรับผู้ดูแล ไฟล์ที่เลือกจะอ่านในเบราว์เซอร์นี้เท่านั้น ไม่ถูกส่งไปที่ใด ผลลัพธ์ที่ได้มีเฉพาะตัวเลขระดับน้ำ 4 ค่า สถานะ และจำนวนอุปกรณ์รายโครงการ ไม่มีชื่อ อีเมล หรือจำนวนผู้พักอาศัย กลับไปที่แดชบอร์ด

1. ข้อมูลสำรวจจากหน้างาน

  1. ส่งออกไฟล์ คำตอบทั้งหมด (.xlsx) จากแบบฟอร์ม แล้วเลือกไฟล์ด้านล่าง
  2. ตรวจตัวเลขสรุป แล้วกด ดาวน์โหลด survey.json
  3. เปิด หน้าอัปโหลดไฟล์ของ GitHub ลากไฟล์ survey.json ไปวาง แล้วกด Commit changes เว็บจะอัปเดตภายในประมาณ 1–2 นาที

2. สถานะตาม ERT Update

ใช้เมื่อ ERT Update ระบุสถานะของโครงการโดยตรง สถานะนี้จะแทนผลจากสูตรจนกว่าจะลบออก แก้ไขแล้วกดดาวน์โหลด ert.json และอัปโหลดแบบเดียวกับข้อ 1

โครงการสถานะหมายเหตุเวลา ERT

3. ระดับน้ำ ThaiWater

ระบบดึงอัตโนมัติทุกชั่วโมง ถ้าต้องการดึงทันที เปิด หน้า Actions เลือก ThaiWater hourly แล้วกด Run workflow
