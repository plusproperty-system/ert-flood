    สรุปสถานการณ์น้ำประจำวัน

    ดึงจาก ThaiWater อัตโนมัติทุกชั่วโมง

    ในจำนวนนี้ เข้าเงื่อนไขอะไรบ้าง

    หนึ่งโครงการเข้าได้หลายเงื่อนไข กดการ์ดเพื่อดูเฉพาะโครงการกลุ่มนั้น กดซ้ำเพื่อยกเลิก

    แผนที่โครงการ แยกตามโซน

    สีหมุดคือสถานะโครงการ วงสีน้ำเงินคืออยู่ในรัศมีสถานีล้นตลิ่ง สามเหลี่ยมคือสถานีวัดระดับน้ำที่เตือน เลื่อนลูกกลิ้งเมาส์บนแผนที่เพื่อซูม ลากเพื่อเลื่อน

    ภาพขยายโซน กทม. และปริมณฑล

    สรุปรายโซน

    ชี้ที่การ์ดเพื่อดูรายละเอียด กดเพื่อกรองทั้งหน้าและซูมแผนที่ไปที่โซนนั้น

    แหล่งน้ำที่ต้องเฝ้าระวัง

    คลอง แม่น้ำ ที่มีสถานีวัดระดับน้ำล้นตลิ่งหรือน้ำมากในรัศมีของโครงการ กดที่แถวเพื่อดูรายละเอียดรายโซนและรายโครงการ กดหัวตารางเพื่อเรียงลำดับ

    แหล่งน้ำระดับเตือนสูงสุดสถานีที่เตือนระดับเทียบตลิ่ง
