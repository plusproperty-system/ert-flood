# ERT Flood · แดชบอร์ดสถานการณ์น้ำท่วมโครงการ PMR (ฉบับสาธารณะ)

เว็บ: เปิดจาก GitHub Pages ของ repo นี้ (Settings › Pages)

## ข้อมูลในเว็บ
| ไฟล์ | ที่มา | อัปเดตโดย |
|---|---|---|
| `docs/data/master.json` | รายชื่อโครงการ โซน เขต จังหวัด พิกัด (`fl` = ผลกระทบตามทะเบียนผลกระทบ 2569) ไม่รวมโครงการสถานะ Reject/Terminate | แก้เมื่อมีโครงการใหม่ |
| `docs/data/survey.json` | ไฟล์ "คำตอบทั้งหมด" (3 ชีต) แปลงผ่าน `admin.html` (ตัวเลขระดับน้ำ สถานะ อุปกรณ์ และข้อมูลอาคาร `fx`: ระดับเทียบถนน ชั้นใต้ดิน/ห้องเครื่อง/ลิฟต์ใต้ดิน Automated Parking ไม่มีจำนวนคน) | ผู้ดูแล อัปโหลดเอง หรือซิงก์จากแดชบอร์ด |

| `docs/data/water/*.json` | ระดับน้ำ ThaiWater และสถานีในรัศมีของแต่ละโครงการ | GitHub Actions เมื่อกดปุ่มอัปเดตข้อมูลน้ำ (Update water data) |
| `docs/data/rivers.json` | ระยะจากโครงการถึงแม่น้ำและคลองที่ใกล้ที่สุด (OpenStreetMap) | GitHub Actions เดือนละครั้ง และเมื่อแก้ master.json |
| `docs/data/bma/*.json` | ระดับน้ำคลอง กทม. เทียบตลิ่ง จากเว็บสำนักการระบายน้ำ (weather.bangkok.go.th/water) | GitHub Actions เมื่อกดปุ่มอัปเดตข้อมูลน้ำ (Update water data) |
| `docs/data/waterways.json` | เส้นแม่น้ำและคลองสำหรับวาดบนแผนที่ (OpenStreetMap) | GitHub Actions พร้อมกับ rivers.json |
| `docs/data/geo.json` | ขอบเขตโซนและจังหวัดสำหรับแผนที่ | ไม่ต้องแก้ |

ห้ามอัปโหลดไฟล์ Excel ต้นฉบับเข้า repo นี้ เพราะ repo เป็นสาธารณะ ใช้ `admin.html` แปลงก่อนเสมอ (ไฟล์ที่แปลงแล้วมีเฉพาะตัวเลขระดับน้ำ สถานะ และจำนวนอุปกรณ์/เสบียง ไม่มีชื่อหรืออีเมล)

## อัปเดตข้อมูลสำรวจ
1. เปิด `admin.html` บนเว็บ เลือกไฟล์ "คำตอบทั้งหมด"
2. กดดาวน์โหลด `survey.json`
3. ใน GitHub ไปที่ `docs/data` › Add file › Upload files › ลาก `survey.json` › Commit changes

## สถานะตามสูตรประกาศ
ตรวจทีละข้อจากบนลงล่าง (ค่าว่างหรือข้อความนับเป็น 0)
1. น้ำหน้าถนน = 15 และน้ำในท่อ = 50 → เฝ้าระวังพิเศษ
2. ระบบไฟฟ้าใช้ไม่ได้ หรือน้ำในโครงการ ≥ 60 → วิกฤตรุนแรง
3. น้ำในโครงการ > 0 หรือน้ำหน้าถนน ≥ 15 → วิกฤต
4. น้ำหน้าถนน = 0 และน้ำในท่อ = 0 หรือ > 50 → ปกติ
5. น้ำในท่อ ≥ 30 → เฝ้าระวัง
6. ที่เหลือ → วิกฤต

## ระดับน้ำ ThaiWater
`scripts/thaiwater.py` ใช้เกณฑ์เดียวกับไฟล์ PMR_ThaiWater_Mapping_PowerQuery.xlsx: รัศมีแม่น้ำ/ลำน้ำ 10 กม. คลอง กทม. 3 กม. ไม่ใช้สถานีที่ข้อมูลเก่ากว่า 24 ชม. (คลอง 6 ชม.)
ไม่ดึงอัตโนมัติแล้ว กดปุ่ม "อัปเดตข้อมูลน้ำ" บนหน้าเว็บ (เปิด Actions › Update water data) แล้วกด Run workflow สคริปต์จะดึงทั้ง ThaiWater และคลอง กทม. ในครั้งเดียว

## ระยะจากแม่น้ำ
`scripts/rivers.py` ดึงแม่น้ำ (waterway=river) และคลอง (waterway=canal) จาก OpenStreetMap ผ่าน Overpass API แล้ววัดระยะจากพิกัดโครงการ
- ใช้กับโครงการที่มีแถวในแบบสำรวจแต่ไม่มีตัวเลขน้ำหน้าถนน ในท่อ/บ่อ และในโครงการ
- แม่น้ำในรัศมี 3 กม. → เฝ้าระวังพิเศษ, 3–6 กม. → เฝ้าระวัง (ถ้าสูตรได้ระดับที่รุนแรงกว่า ใช้ตามสูตร)
- คลองใช้จัดกลุ่มในหน้าติดตามอุปกรณ์ ไม่ใช้กำหนดสถานะ
ครั้งแรกให้กด Actions › Rivers and canals › Run workflow (ใช้เวลาราว 5–15 นาที)

## ติดตามอุปกรณ์และเสบียง
หน้าภาพรวมมีตารางโครงการสถานะเฝ้าระวังขึ้นไป พร้อมจำนวนกระสอบทราย เครื่องสูบน้ำ ฯลฯ จากชีต "สำรวจอุปกรณ์" จัดกลุ่มตามแม่น้ำ/คลองที่ใกล้ที่สุด กดแถวกลุ่มเพื่อดูรายโครงการ และดาวน์โหลด CSV ได้

## ระดับน้ำคลอง กทม. (สำนักการระบายน้ำ)
`scripts/bma.py` อ่านตารางจุดวัดจาก https://weather.bangkok.go.th/water/ เมื่อกดปุ่มอัปเดตข้อมูลน้ำ (Actions › Update water data)
- ผิวน้ำห่างตลิ่ง (ซม.) = ตลิ่งด้านที่ต่ำกว่า (ซ้าย/ขวา) − ระดับน้ำด้านใน ค่าติดลบคือล้นตลิ่ง จุดที่ไม่มีระดับตลิ่งแสดงระยะถึงระดับวิกฤตแทน
- ข้อมูลเก่ากว่า 3 ชั่วโมงถือว่าค้าง
- เว็บต้นทางไม่มีพิกัดจุดวัด สคริปต์จับคู่ชื่อจุดวัดกับสถานีคลองของ ThaiWater เพื่อเอาพิกัด แล้วบันทึกใน `scripts/bma_coords.csv`
  - จุดวัดที่มีพิกัด: จับคู่โครงการในรัศมี 3 กม.
  - จุดวัดที่ไม่มีพิกัด: จับคู่กับโครงการในเขตเดียวกัน
- แก้หรือเติมพิกัดเองได้ใน `scripts/bma_coords.csv` ใส่ lat, lon และใส่ `manual` ในช่อง source สคริปต์จะไม่เขียนทับแถวนั้น
- ถ้า Actions ล้มเพราะอ่านตารางไม่ได้ (เว็บต้นทางเปลี่ยนหน้าตา) ไฟล์หน้าเว็บจะถูกเก็บไว้ใน Artifacts ชื่อ bma-page เพื่อใช้ปรับสคริปต์

## เส้นทางน้ำบนแผนที่
แผนที่ทั้งสองวาดแม่น้ำและคลองเป็นสีฟ้า ยิ่งเข้มยิ่งน่าเป็นห่วง
- ฟ้าอ่อน: ปกติหรือไม่มีสถานีวัด
- ฟ้ากลาง: มีสถานีน้ำมาก (ชื่อตรงกับแหล่งน้ำที่ ThaiWater เตือน หรือห่างสถานีที่เตือนไม่เกิน 1.5 กม.)
- น้ำเงินเข้ม: มีสถานีล้นตลิ่ง (หรือจุดวัดคลอง กทม. ที่วิกฤต/ล้นตลิ่ง)
ก่อนรัน Rivers and canals ครั้งแรก แผนที่ใช้แม่น้ำสายหลักจาก Natural Earth (ไม่มีคลอง) หลังรันแล้วจะใช้ `waterways.json` จาก OpenStreetMap

## ชื่อโครงการในแบบสำรวจที่ไม่ตรงกับ Master
`admin.html` มีตารางคู่ชื่อ (ALIAS) สำหรับชื่อในระบบแบบสำรวจที่ต่างจาก Master เช่น "อาคาร ปาโซ่ ทาวเวอร์" = "ปาโซ่ ทาวเวอร์" ชื่อที่จับคู่ไม่ได้จะแสดงเป็นรายการหลังเลือกไฟล์

## Excel สรุปความเสี่ยง 6 ประเภท
ปุ่ม "ดาวน์โหลด Excel สรุปความเสี่ยง 6 ประเภท" ในหน้าแรกสร้างไฟล์จากข้อมูลล่าสุดของเว็บ (ชีตสรุป + ชีตรายละเอียด) ไม่มีไฟล์ Excel เก็บใน repo
1. ใกล้คลอง/แม่น้ำ: ระยะจาก rivers.json ไม่เกิน 1 กม.
2. ต่ำกว่าถนน: `fx.e` < 0
3. มีใต้ดิน/เครื่องจักรใต้ดิน: ชั้นใต้ดิน ลานจอดรถ ห้องเครื่อง หรือลิฟต์ใต้ดิน อย่างใดอย่างหนึ่ง
4. ประวัติน้ำเคยท่วม: อยู่ในทะเบียนผลกระทบ 2569 (`fl` ใน master.json)
5. Automated Parking: `fx.ap`
6. เขตทางผ่านของน้ำ: จังหวัด/เขตใน `FW_AREAS` ของ index.html (เสนอจากแนวน้ำปี 2554)
เกณฑ์ข้อ 1, 2 และรายชื่อพื้นที่ข้อ 6 แก้ได้ในไฟล์ที่ดาวน์โหลด ตัวเลขทั้งไฟล์คำนวณตามสูตร
